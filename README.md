# Prism Lib — Color Utility API

[![Download Latest](https://img.shields.io/github/v/release/Avenueorbang/prism-lib-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/Avenueorbang/prism-lib-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A shared library providing color handling utilities and palette APIs for Minecraft mods.

![Prism Lib — Color Utility API Preview](https://cdn.modrinth.com/data/oLV8Vvxy/7e9d2410e1efec3ca557cac05b18797a5bd6771e_96.webp)

## Features

- HSV, HSL, and RGB color conversion utilities
- Palette loading from resource packs
- Dye-aware color mapping for blocks and entities
- Dynamic color provider hooks for mod items
- Lightweight dependency used by cosmetic mods

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
